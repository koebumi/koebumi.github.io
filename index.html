01なぜKoebumiか

話した言葉は、
そのままでは指示にならない。

話したままの文には「えーと」が残り、ファイル名はカタカナで書かれ、コマンドは「スラッシュ コンパクト」という文になります。Koebumiは画面にClaude CodeやCodexを見つけると、話した内容をエージェントへの指示として整えます。

02Claude Code ・ Codex

キーボードに、
手を戻さない。

ターミナルにClaude CodeやCodexが出ていると、話した内容をエージェントへの指示として入力します。下の見本は、すべてKoebumiで実際に試した結果です。

01 / 04 ・ PERMISSION

許可の確認に、声で答える

Claude Codeが「Do you want to proceed?」と聞いてきたら、「はい」「今後は聞かないで」「いいえ」「2番」と話して選べます。「いいえ、先にビルドだけして」と続けると、Noを選んでから続きを送ります。

「はい」
claude ・ ~/project
02 / 04 ・ SLASH COMMANDS

スラッシュコマンドも、自作のスキルも

「スラッシュ コンパクト」と話すと、整形せずに/compactと入力します。~/.claude/skillsや~/.codex/promptsにある自作のコマンドも、名前で呼べます。日本語の名前のスキルは、読みで探します。

「スラッシュ コンパクト」と話すと/compact
「スラッシュ コードレビュー」と話すと/code-review
「スラッシュ グリルミー」と話すと/grill-me
「スラッシュ よみやす」と話すと/yomiyasu日本語の名前
03 / 04 ・ FILE NAMES

ファイル名は、リポジトリの表記で

話したファイル名を、作業フォルダにある実際の表記に直します。gitのリポジトリで動いているエージェントなら、設定はいりません。

「ストレージドットスウィフトのコメントを見直して」Storage.swiftのコメントを見直して
「リードミーファイルに使い方を足して」README ファイルに使い方を足して
「あの、エージェントインプットの関数を分けて」AgentInputの関数を分けて
04 / 04 ・ SEND

最後に「送信」で、Enterまで

文の最後に「送信」と言うと、入力してからEnterを押します。「送信」だけを話すと、入力欄にある文を送ります。「データを送信」のように文の中で使った語は、命令とみなしません。

えーと、ファイルネームフィクサーのテストを追加して、送信
Claude Codeに入力して送るFileNameFixerのテストを追加して↵ Enter

プロセスではなく画面の文字で見分けるので、tmuxやherdrの中、SSHの先で動いていても使えます。

FILLER

言いよどみを除く

「えーと」「あの」を取り除き、話した中身だけを残します。

会議は火曜日、いや水曜日にしましょう
Koebumiが入力会議は水曜日にしましょう。

CORRECTION

言い直しを反映

「いや」「違う」「やっぱり」で言い直したら、言い直した後だけを残します。

資料は三時までに送って下さい
Koebumiが入力資料は3時までに送ってください。

NOTATION

表記をそろえる

数字は算用数字に、補助動詞はひらがなに。AIに任せず決まった規則で直すので、崩れません。

あ、来週の打ち合わせなんですけど、ちょっと遅れて参加します
Koebumiが入力（メール）来週の打ち合わせですが、少し遅れて参加いたします。

KEIGO

メールは、ていねいに

くだけた話し方でも、メールではビジネスの文に直します。

明日やることは3つです。1つ目は資料、2つ目は見積もり、3つ目は日程の確認です
Koebumiが入力（メモ）明日やることは3つあります。
  1. 資料
  2. 見積もり
  3. 日程の確認

LISTS

箇条書きに

「1つ目は」「2つ目は」と並べて話すと、番号付きの箇条書きにします。

えーと、明日の会議は4時からです。資料は事前に送ります
Koebumiが入力（英語）The meeting starts at 4 tomorrow. I will send the materials in advance.

07プライバシー

プライバシーは、
最初から。

APIキーは、いりません

Appleのオンデバイスモデルと、このMacで動く音声認識で使えます。オフラインでも動きます。

保存はこのMacだけ

履歴・録音・辞書・学習内容は、このMacにだけ保存します。履歴を「保存しない」も選べます。

画面の文字は保存しない

人名や用語の表記を合わせるため、Claude Codeを見分けるために画面を読みますが、読んだ内容は保存しません。パスワード欄は読みません。

クラウドは、選んだときだけ

ClaudeやOpenAI互換のエンジンを選んだときは、録音か書き起こした文を、選んだサービスに送ります。

08よくある質問

気になるところ。

ここにない質問や不具合は、GitHubのIssuesに送ってください。

本当に無料ですか？

はい。MIT Licenseのオープンソースで、アプリに料金はかかりません。ClaudeやOpenAI互換のエンジンを選んだときだけ、そのサービスの利用料がかかります。

APIキーがなくても使えますか？

使えます。既定では、Appleのオンデバイスモデルと音声認識を使います。このMacで動く音声認識モデル（5種類）も、キーなしで選べます。

どのMacで動きますか？

macOS 26以降の、AppleシリコンのMacです。Appleのオンデバイスモデルで整形するには、Apple Intelligenceをオンにしてください。WindowsやiPhoneの版はありません。

話した内容は、どこへ送られますか？

既定では送りません。音声認識も整形も、このMacの中で行います。ClaudeやOpenAI互換のエンジンを選んだときだけ、録音か書き起こした文を、選んだサービスに送ります。

「開けませんでした」と表示されて開けません

まだAppleの公証を受けていないためです。「完了」を押してから、システム設定 > プライバシーとセキュリティを開き、「Koebumi」の「このまま開く」を押してください。必要なのは最初の1回だけです。

Codexでも使えますか？

使えます。整形、ファイル名の修正、スラッシュコマンド、「送信」でのEnterは、Codexでも動きます。許可の確認に声で答えられるのは、Claude Codeだけです。

tmuxやSSHの先のClaude Codeでも使えますか？

使えます。プロセスではなく画面の文字で見分けるので、tmuxやherdrの中、SSHの先でも動きます。ただし、tmuxで画面を左右に分けているときは、許可の確認には答えません。

ClaudeやChatGPTのサブスクで整形できますか？

できます。このMacのClaude CodeやCodexを起動して整形するので、それぞれと同じ利用枠を使います。Koebumiはログインのトークンに触れません。各社の規約や方針が変わると、使えなくなることがあります。

日本語以外でも使えますか？

使えます。このMacで動くモデルは、話した言語を自動で判定します。翻訳先を選べば、日本語で話して英語で入力することもできます。アプリの表示は日本語と英語です。

新しい版は、どう入れますか？

新しい版が出ると、Koebumiが知らせます。確認のために1日1回GitHubにアクセスします。設定 > 一般でオフにできます。

09入れ方

3つの手順で、
使い始める。

  1. ダウンロードする

    ReleasesからKoebumi-<版>.zipをダウンロードして開き、Koebumi.appを「アプリケーション」フォルダに入れます。

  2. 最初の1回だけ「このまま開く」

    「開けませんでした」と出たら、システム設定 > プライバシーとセキュリティで「このまま開く」を押します。まだAppleの公証を受けていないためです。

  3. マイクとアクセシビリティを許可

    セットアップ画面に沿って許可し、Fnキー（地球儀キー）を押したときの動作を変えます。新しい版は、アプリが知らせます。
